🌐 What is Poly-Glot?

Poly-Glot AI Workspace is a multilingual AI workspace for creating better prompts, working across languages, and comparing answers from leading AI assistants in one workflow. It includes 1,000+ prompt templates, support for 38 languages, Compare Mode, and developer-facing MCP tools.

The app is available for Apple devices, while the Poly-Glot MCP server brings the same prompt-building and language tools directly into compatible AI assistants such as Claude and ChatGPT. Use the links below to explore the product, install the app, or inspect the public implementation.

🔌 What is MCP?

MCP (Model Context Protocol) lets compatible AI assistants and developer tools connect to external tools. Poly-Glot uses a remote Streamable HTTP MCP server. A supported MCP client is one that can connect to that type of remote MCP endpoint. Once connected, the client can use Poly-Glot tools for templates, prompt building, language workflows, and comparison preparation.

MCP client compatibility

Supported means the client supports a remote Streamable HTTP MCP server like Poly-Glot's production endpoint. Connection steps and UI can vary by client, but supported clients use the same Poly-Glot MCP endpoint and the same server-side tool and entitlement logic.

❓ FAQ

Is it free?

Poly-Glot includes a 3-day full-access trial. After the trial, 25 Free templates remain available and share one free single-AI Send every rolling 24 hours. Pro unlocks Pro templates, Compare Mode, and unlimited Sends.

Do I need the iOS/macOS app?

No. MCP works independently — connect directly from Claude or ChatGPT. The app is optional for browsing templates visually and managing your subscription.

Is my data private?

Yes. Poly-Glot doesn't store your prompts or conversations. Template data flows directly between you and your AI assistant. See our Privacy Policy.

What AI providers work with Compare Mode?

Compare across any 2–9 providers: ChatGPT, Claude, Gemini, Grok, Perplexity, Copilot, Mistral, HuggingChat, and DuckDuckGo AI.

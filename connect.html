🔌 What is MCP?

MCP (Model Context Protocol) lets compatible AI assistants and developer tools connect to external tools. Poly-Glot uses a remote Streamable HTTP MCP server. A supported MCP client is one that can connect to that type of remote MCP endpoint. Once connected, the client can use Poly-Glot tools for templates, prompt building, language workflows, and comparison preparation.

MCP client compatibility

Supported means the client supports a remote Streamable HTTP MCP server like Poly-Glot's production endpoint. Connection steps and UI can vary by client, but supported clients use the same Poly-Glot MCP endpoint and the same server-side tool and entitlement logic.

goose MCP Client

goose supports MCP extensions and multiple MCP servers. In a goose build that exposes a remote HTTP/URL extension option, add Poly-Glot as a custom remote MCP extension using the production endpoint below, then enable the extension and approve its tools.

Important: goose's extension UI and transport options can vary by release. If your build only offers command/stdio extensions, do not paste the URL into a command field; use a goose version or connection path that supports remote HTTP MCP.

Any other Streamable HTTP MCP client

Open the client's MCP / Tools / Integrations settings

Look for Add server, Add connector, Custom MCP, or Remote MCP.

Select remote HTTP / Streamable HTTP

Do not choose stdio unless the client is wrapping the remote endpoint for you.

Paste the production endpoint
https://br-steep-leaf-ae2o29qz-mcp.compute.c-2.us-east-2.aws.neon.tech/mcp
Name it Poly-Glot, connect, and approve tools

After the client completes the MCP handshake, it should discover the same 15 server-side Poly-Glot tools.

Directories are not clients: Official MCP Registry, MCP.so, Glama, and the Hugging Face listing are discovery/inspection surfaces. You do not create a separate Poly-Glot server for each directory. Use the same production endpoint in the MCP client you actually use.

❓ FAQ

Is it free?

Poly-Glot includes a 3-day full-access trial. After the trial, Compare Mode and Pro templates lock unless you subscribe to Pro. The Free plan retains 25 featured templates and one shared single-AI Send every rolling 24 hours.

Do I need the iOS/macOS app?

No. MCP works independently — connect directly from Claude or ChatGPT. The app is optional for browsing templates visually and managing your subscription.

Is my data private?

Yes. Poly-Glot doesn't store your prompts or conversations. Template data flows directly between you and your AI assistant. See our Privacy Policy.

What AI providers work with Compare Mode?

Compare across any 2–9 providers: ChatGPT, Claude, Gemini, Grok, Perplexity, Copilot, Mistral, HuggingChat, and DuckDuckGo AI.
